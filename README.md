# موقع عبدالماجد العيلي — النسخة التفاعلية

تشغيل: python3 -m http.server 8000 ثم http://localhost:8000

الأكواد: index.html للبنية، style.css للهوية والتجاوب، app.js للتفاعلات وبيانات المشاريع، portfolio-data.js لصور المشاريع.

## الأدوات الجديدة
قسم consultation-tools يتضمن تقييمًا من أربع خطوات، حفظ الاختيارات عند الرجوع، نتائج تعتمد على جميع الإجابات، وملخصًا قابلًا للتحويل إلى واتساب أو نموذج التواصل. لا تُرسل البيانات تلقائيًا.
خارطة التنفيذ تتغير حسب النشاط والمساحة، وتعرض أربع مراحل ومددًا تراكمية ومخاطر قابلة للفتح في نافذة.

## تخصيص المنطق
في app.js: readinessQuestions للأسئلة، assessReadiness لمصفوفة النصائح، planTimeline لافتراضات المدد، phaseContent لمحتوى المخاطر. الأرقام افتراضات أولية صريحة؛ راجعها مع صاحب المكتب قبل اعتمادها تجاريًا. النطاق أكثر من 300م² عام؛ المشروعات الكبيرة قد تتجاوز المدد.

## التحقق
اختُبرت 192 تركيبة إجابات و9 إعدادات للجدول، مع صحة المجاميع والمدخلات. وتحقق يدويًا من التقييم وتعبئة النموذج وتغيير المخطط وفتح المخاطر. الاختبارات المنطقية في tests/consultation.cjs وتشغّل من جذر الحزمة: node tests/consultation.cjs.

## حدود قائمة
FormSubmit يحتاج تفعيل بريد صاحب الموقع واختبار التسليم. لم تُرسل رسائل اختبار. الخرائط بحث مضمّن وليست إحداثيات موثقة لجميع الفروع. صور المشاريع تصورات تصميمية؛ أوقفت الصور ذات التوقيعات وفق طلب المالك. الخط يعتمد على CDN. الموقع المستضاف خاص بصاحبه. لا تتضمن الحزمة مفاتيح وصول أو إعدادات الاستضافة.
