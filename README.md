# موقع عبدالماجد العيلي

موقع ثابت باللغة العربية، دون بناء أو اعتماديات تشغيل. شغّل `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.

البنية في index.html وlibrary.html وprivacy.html، والهوية في style.css وenhancements.css وorganization.css. الخطوط والصور محلية داخل assets/. بيانات المشاريع المعتمدة في project-data.js، والدروس في learning-data.js.

الأدوات تعمل داخل المتصفح؛ لا تُرسل الإجابات إلا باختيار الزائر قناة التواصل. اختبارات المنطق: `node tests/consultation.cjs`.

نموذج البريد يستخدم FormSubmit، وواتساب بديل متاح. ملاحظات المحتوى المطلوب من المالك موجودة في تعليقات HTML فقط. الخرائط روابط خارجية وليست خدمة خرائط مضمّنة. لا توجد مفاتيح سرية داخل الموقع.

الأرقام المعتمدة قابلة للتعديل من عناصر data-stat في index.html. تقرير التحقق والمهام المتبقية في POLISH-REPORT.md. صور المراجعة محلية داخل qa-screenshots/ ومستثناة من Git.
